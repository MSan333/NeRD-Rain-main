# NeRD-Rain 实验记录

## 一、消融实验结果（Rain200L 测试集，Y-channel）

| 配置 | PSNR (dB) | SSIM | 相比 Baseline 提升 | 单模块贡献 |
|------|-----------|------|-------------------|-----------|
| Baseline | 41.71 | 0.9903 | - | - |
| 创新点1（AttSSM） | 41.78 | 0.9906 | +0.07 | +0.07 |
| 创新点1 + 创新点3（BFPU） | 41.89 | 0.9905 | +0.18 | +0.11 |
| 创新点1 + 创新点2（MFGCP）+ 创新点3（BFPU） | 41.93 | 0.9907 | +0.22 | +0.04 |

### 各创新点贡献分析

| 创新点 | 模块名称 | 独立贡献 | 评价 |
|--------|---------|---------|------|
| 创新点1 | AttSSM（注意力状态空间模型） | +0.07 dB | 核心架构改进，贡献中等 |
| 创新点2 | MFGCP（多尺度特征引导上下文传播） | +0.04 dB | 贡献偏弱，有改进空间 |
| 创新点3 | BFPU（双向特征传播单元） | +0.11 dB | 贡献最大，涨分主力 |

### 问题与观察

1. **MFGCP 贡献偏低**：仅 +0.04 dB，审稿人可能质疑其有效性
2. **SSIM 异常**：创新点1+3 的 SSIM (0.9905) 反而低于单独创新点1 (0.9906)，加入 MFGCP 后回升至 0.9907
   - 推测：MFGCP 更多在修复创新点3引入的某些结构性副作用，而非提供独立增益
3. **改进方向**：需要用更强的模块替代 MFGCP，目标是将创新点2的贡献提升到 +0.1 dB 以上

## 二、续训实验记录

### 训练路径总览

```
exp3_lr1e4 (初始训练)
    └── exp3_lr7e5 (续训, lr=7e-5)
            └── exp3_lr4e5 (续训, lr=4e-5)
                    ├── exp3_lr5e5_4gpu (4卡, lr=5e-5)
                    │       └── exp3_lr2e5 (2卡, lr=2e-5) ← 产出 41.92 best
                    │               └── exp3_lr2e5_4gpu (4卡, lr=2e-5) ← 产出 41.93 best (当前最优)
                    │                       └── exp3_lr1e5 (2卡, lr=1e-5, 进行中)
                    └── ...
```

### 各阶段详细记录

| 实验名称 | GPU配置 | 学习率 | 从哪个Best恢复 | 训练验证Best PSNR | 测试Y-ch PSNR | 测试SSIM | 备注 |
|---------|---------|--------|---------------|-----------------|--------------|----------|------|
| DDP_2GPU_exp3_lr1e4 | 2卡 | 1e-4→1e-6 | 从头训练 | - | 41.8340 | 0.9904 | 初始训练 |
| DDP_2GPU_exp3_lr7e5 | 2卡 | 7e-5→1e-6 | lr1e4/best | - | 41.8591 | - | lr过大，震荡不收敛 |
| DDP_2GPU_exp3_lr4e5 | 2卡 | 4e-5→1e-6 | lr7e5/best | 40.1688 | - | - | 有效但提升缓慢 |
| DDP_4GPU_exp3_lr5e5 | 4卡 | 5e-5→1e-6 | lr4e5/best | 40.1968 | - | - | 4卡探索，200epoch |
| DDP_2GPU_exp3_lr2e5 | 2卡 | 2e-5→1e-6 | lr5e5_4gpu/best | 40.2078 (ep355) | 41.9201 | 0.9907 | 重大突破 |
| DDP_4GPU_exp3_lr2e5 | 4卡 | 2e-5→1e-6 | lr2e5/best | 40.2165 (ep370) | **41.9277** | **0.9907** | **当前全局最优** |
| DDP_2GPU_exp3_lr1e5 | 2卡 | 1e-5→1e-6 | 4gpu_lr2e5/best | 40.2057 (ep371) | - | - | 进行中 |

### 关键发现

1. **学习率选择**：续训 lr 不宜过高（7e-5 震荡）也不宜过低（1e-5 提升极慢），2e-5 是当前最优
2. **GPU 数量影响**：4 卡 (batch=4) 比 2 卡 (batch=2) 梯度更稳定，更容易突破瓶颈
3. **收益递减**：从 41.83 → 41.86 → 41.92 → 41.93，提升越来越困难
4. **训练验证 vs 测试指标差异**：训练验证 PSNR（RGB torchPSNR）约 40.x，测试 Y-channel PSNR 约 41.x，差异约 1.7-1.8 dB
