CURRENT CHALLENGES

三大核心痛点

痛点 1 — 忽视雨纹的频域特征分布

雨纹在频域呈现周期性模式，但大多数方法仅在空域处理

痛点 2 — 缺乏对雨纹方向性结构的显式建模

雨纹具有强方向先验（水平/竖直/对角），通用卷积无法有效捕获

痛点 3 — 训练中频域信息利用不足

标准 L1/L2 损失无法引导模型关注不同频段的恢复优先级

创新点 1 · RFM

残差频域模块
Residual Frequency Module

针对痛点 1 — 引入频域显式建模

在频域中直接操作幅度谱，增强被雨纹掩盖的频率成分

RFM · 结构图

残差频域模块流程

RFM · 公式

残差频域增强

频域增强特征
Fenhanced = Conv( |FFT(x)| ) · e j · Phase(FFT(x))

残差输出
xout = x + iFFT( Fenhanced )

幅度谱经两层 1×1 Conv + ReLU 增强，相位保持不变，最终通过残差连接融合

频域建模带来稳定提升

+0.08 dB

Rain200L · PSNR 提升

MFGCP · 融合机制

TransformerBlock 更新规则

创新点 3 · HAFL

分层自适应
频域损失

针对痛点 3 — 训练策略层面频域约束

Hierarchical Adaptive Frequency Loss

HAFL · 频域分解

三子带频域分解示意图

HAFL · 课程学习策略

渐进式权重调度曲线

先学结构，再学纹理，最后学细节

HAFL · 公式

分层自适应频域损失

HAFL 损失
LHAFL = wlow · L1(Xlow, Ylow) + wmid · L1(Xmid, Ymid) + whigh · L1(Xhigh, Yhigh)

权重调度
wlow = 0.8
wmid = 0.5 · min(1, 2t)
whigh = 0.3 · max(0, 3(t − 1/3))

t = epoch / total_epochs，训练进度归一化到 [0, 1]
低频始终全权重；中频前半段线性增长；高频延迟至 1/3 进度后启动

总损失函数

多目标联合优化

总损失
Ltotal = Lchar + 0.01 · Lfft + 0.05 · Ledge + 0.1 · Ll1 + 0.1 · LHAFL

Lchar : Charbonnier 损失（主损失）
Lfft : 频域幅度损失
Ledge : 边缘感知损失
Ll1 : 标准 L1 损失
LHAFL : 分层自适应频域损失（新增）

在 RFM 基础上的额外 PSNR 提升
