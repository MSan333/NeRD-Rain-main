### 原图风格分析（NeRD-Rain CVPR 2024）

原图采用**左右分区**布局：
- **左侧**（灰色底色区）：INR模块内部细节放大
  - Pixel Coordinate → Coarse/Fine Grid → Feature-Grid Interpolation → MLP → RGB
  - 展示了多尺度输入（¼ Input, ½ Input）和自适应拟合过程
  - 特征网格插值节点用彩色圆点表示（红/绿/蓝点 = 不同样本点）

**视觉风格要素**：
- 模块色块：深蓝=Encoder，浅蓝=Shared Encoder，橙色=Bottleneck，绿色=Decoder，黄绿=Conv3×3

- 实际图片缩略图穿插在输入/输出/GT位置
- 圆形符号：⊕、⊗、C、S、↑
- 灰色底色区域包裹细节放大部分

```

┌── 2D-FFT ──┐
│  F = FFT(x) │
└──┬──────┬──┘
   ↓      ↓
 ┌────┐ ┌────┐
 │ A  │ │ φ  │   (幅度谱 & 相位谱)
 │幅度│ │相位│

   ↓      │

│Conv1×1   │ │
│  ↓       │ │
│ ReLU     │ │
│  ↓       │ │
│Conv1×1   │ │
│  ↓       │ │
│ Sigmoid  │ │
│  = A'    │ │
└──┬───────┘ │
   ↓         ↓
┌──────────────┐
│ F' = A'·e^jφ │  (重构复数频谱)
└──────┬───────┘
       ↓

       ↓

       ↓

## 五、HAFL 渐进式课程学习权重变化图

**用途**：创新点3详细阐述处

**类型**：折线图

**X轴**：训练进度 t = epoch/total_epochs (0→1)
**Y轴**：损失权重 (0→1)

**三条曲线**：
- **w_low = 0.8**（蓝色水平线，恒定）

- **w_high = 0.3 × min(1, max(0, 3(t-1/3)))**（红色，t<1/3时为0，之后线性上升到0.3，在t=2/3时饱和）

- 三个阶段分区：Phase 1 (低频主导) | Phase 2 (中频引入) | Phase 3 (高频精细化)

Step 3: 空间分组聚合 (group_size=4)
┌──────────────────────────┐
│ 保留: [T1][T2]...[T128]  │  128 tokens (原样)
│ 聚合: [G1][G2]...[G32]   │  128/4 = 32 代表tokens
│ 总计: M = 160 tokens      │
└──────────────────────────┘
        ↓
Step 4: 压缩注意力计算
┌────────────────────────────────────┐
│  Q (256) × K^T (160) → Attn (256×160) │
│  计算量: N×M = 256×160 vs N×N = 256×256 │
│  节省: 37.5%                        │
└────────────────────────────────────┘
```

**可视化形式**：
- Step 1 用热力图色块表示每个 Token 的密度
- Step 2 用★和□区分保留和待聚合
- Step 3 用分组括号表示聚合过程
- Step 4 用矩阵大小对比图
