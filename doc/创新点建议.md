# NeRD-Rain 创新点方案

## 项目背景

NeRD-Rain是一个基于双向多尺度隐式神经表示的图像去雨网络（CVPR 2024）。项目核心技术栈包括：PyTorch、State Space Model (Mamba/SSM)、隐式神经表示(INR)、频域处理(FFT)、多尺度编解码器 + 注意力机制。

## 现有创新点

### 创新点1：RFM — 残差频域模块（Residual Fourier Module）

**实现位置**：model.py 第118-159行

**技术原理**：
- 三分支结构：频域分支 + 空域残差分支 + 融合输出
- 频域分支：FFT → 分离幅度谱和相位谱 → 分别用1x1卷积处理 → 重构复数频谱 → iFFT
- 空域分支：3×3深度可分离卷积增强高频细节
- 输出：频域分支 + 空域残差分支

**创新之处**：
- 双域融合：频域捕获全局雨纹模式，空域保留局部细节
- 幅度-相位分离处理
- 参数高效：仅6个1x1卷积 + 1个DWConv

**性能提升**：Rain200L消融实验 baseline 41.13 → +RFM 41.55 (+0.42 dB)

**集成方式**：以RFM_TransformerBlock形式并行集成到Transformer块的FFN分支中，部署在三个尺度的瓶颈层（共11个实例）。

## 新增创新点建议

### 创新点2：MFGCP — 多尺度频域-梯度协同感知模块

**全称**：Multi-Scale Frequency-Gradient Collaborative Perception Module

**核心思想**：
在RFM的基础上，引入多方向梯度感知分支与频域处理协同工作，通过分离处理幅度和相位谱并结合梯度信息，更精准地区分雨纹特征与背景细节。在不同尺度上独立进行该协同处理，使得小雨纹和大尺度纹理都能被有效恢复。

**参考论文**：
1. DeRainMamba: A Frequency-Aware State Space Model with Detail Enhancement for Image Deraining (IEEE SPL, 2025)
   - 提出频率感知状态空间模块（FASSM）和多方向感知卷积（MDPConv）
2. An Efficient Texture-Aware State Space Model for Image Restoration (IJCAI, 2025)
   - 纹理感知的自适应处理，区分不同区域复杂度
3. Hybrid Frequency Modulation Network for Image Restoration (IJCAI, 2024)
   - 频域调制的高效设计

**技术路线**：
```
输入特征 F_in
    │
    ├── 分支1：频域处理（现有RFM增强版）
    │   FFT → |A(X)|, ∠P(X) → 分别卷积处理 → IFFT
    │
    ├── 分支2：多方向梯度感知（MDPConv）
    │   水平/竖直/对角线方向卷积 → 恢复局部结构细节
    │
    └── 自适应融合（可学习权重）
        │
        输出：增强的多尺度特征
```

**伪代码实现**：
```python
class MFGCPBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.rfm = RFM(channels)  # 现有RFM模块
        self.mdp_conv = MultiDirectionalPerceptionConv(channels)  # 多方向感知卷积
        self.fusion_weight = nn.Parameter(torch.ones(1))  # 可学习融合权重
        
    def forward(self, x):
        freq_out = self.rfm(x)           # 频域分支
        grad_out = self.mdp_conv(x)      # 梯度分支
        output = freq_out + self.fusion_weight * grad_out + x  # 自适应融合
        return output

class MultiDirectionalPerceptionConv(nn.Module):
    def __init__(self, channels):
        super().__init__()
        # 水平、竖直、对角线三方向卷积
        self.horizontal = nn.Conv2d(channels, channels, (1, 3), padding=(0, 1), groups=channels)
        self.vertical = nn.Conv2d(channels, channels, (3, 1), padding=(1, 0), groups=channels)
        self.diagonal = nn.Conv2d(channels, channels, 3, padding=1, groups=channels)
        self.proj = nn.Conv2d(channels * 3, channels, 1)
        
    def forward(self, x):
        h = self.horizontal(x)
        v = self.vertical(x)
        d = self.diagonal(x)
        return self.proj(torch.cat([h, v, d], dim=1))
```

**与现有架构的结合方式**：
1. 保留RFM作为核心频域模块
2. 在编码器各层后添加MDPConv分支
3. 解码器对应层进行特征融合
4. 多尺度框架中重复应用（与双向多尺度结构天然配合）

**预期效果**：
- PSNR提升 0.5-1.5 dB（相比单纯RFM）
- 细节保护更好，SSIM明显提升
- 对不同类型雨纹的适应性提高
- 计算复杂度增加可控

**创新贡献**：
- 相比RFM：添加梯度感知，弥补频域处理忽略的空间细节
- 相比DeRainMamba：将其思想集成到现有INR框架中
- 互补性：RFM主要抑制雨纹，MFGCP加强细节恢复

### 创新点3：SACS-IIG — 场景自适应色彩空间转换与隐式光照引导

**全称**：Scene-Adaptive Color Space Transformation with Implicit Illumination Guidance

**核心思想**：
针对夜间/低光去雨场景，引入可学习的色彩空间变换器，将RGB空间自适应地映射到更有利于去雨的颜色空间，并融合隐式光照引导信息，使得隐式神经表示能够同时学习雨纹移除和光照补偿。这一设计将NeRD-Rain从白天去雨扩展到全天候去雨。

**参考论文**：
1. Rethinking Nighttime Image Deraining via Learnable Color Space Transformation (NeurIPS, 2025)
   - 可学习色彩空间变换器（CSC）+ 隐式光照引导
   - 新数据集HQ-NightRain
2. DPIR: Dual Prompting Image Restoration with Diffusion Transformers (CVPR, 2025)
   - 多维条件信息提取思想
3. HIIF: Hierarchical Encoding based Implicit Image Function (CVPR, 2025)
   - 隐式函数的分层编码，与现有INR结构兼容

**技术路线**：
```
输入图像 I (RGB)
    │
    ├── 可学习色彩空间变换
    │   变换矩阵 C = f(I)  （输入自适应）
    │   I' = C · I  → 映射到有利于去雨的色彩空间
    │
    ├── 隐式光照引导
    │   INR_L(x, y) → 估计局部光照分布
    │   编码到隐式函数中指导雨纹识别
    │
    └── 进入NeRD-Rain编解码器处理
        │
        解码器输出 → 逆色彩空间变换 → 清晰RGB图像
```

**伪代码实现**：
```python
class LearnableColorSpaceTransform(nn.Module):
    def __init__(self, in_channels=3):
        super().__init__()
        self.transform_matrix = nn.Parameter(torch.eye(3))  # 3x3变换矩阵
        self.bias = nn.Parameter(torch.zeros(3))
        
    def forward(self, x):
        b, c, h, w = x.shape
        x_reshaped = x.view(b, c, -1)  # B,C,HW
        transformed = torch.matmul(self.transform_matrix, x_reshaped) + self.bias.view(3, 1)
        return transformed.view(b, c, h, w)

class ImplicitIlluminationGuidance(nn.Module):
    def __init__(self, hidden_dim=256):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(2 + hidden_dim, hidden_dim),  # 坐标 + 基础编码
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)  # 输出亮度值
        )
    
    def forward(self, coords, pos_encoding):
        combined = torch.cat([coords, pos_encoding], dim=-1)
        illumination = self.mlp(combined)
        return illumination

class SACS_IIG(nn.Module):
    def __init__(self, hidden_dim=256):
        super().__init__()
        self.color_transform = LearnableColorSpaceTransform()
        self.illumination_guide = ImplicitIlluminationGuidance(hidden_dim)
        self.inverse_transform = LearnableColorSpaceTransform()  # 逆变换
        
    def forward(self, x, coords, pos_encoding):
        # 前向色彩空间变换
        x_transformed = self.color_transform(x)
        # 光照引导
        illum = self.illumination_guide(coords, pos_encoding)
        return x_transformed, illum
```

**与现有架构的结合方式**：
1. 在NeRD-Rain编码器前添加色彩空间适配层
2. 在INR的坐标编码部分融合光照分支
3. 输出端添加逆色彩空间变换
4. 损失函数增加光照约束项：L_total = L_reconstruction + λ_illum × L_illumination

**预期效果**：
- 夜间去雨PSNR +1-2 dB
- 低光条件适应性大幅提高
- 色彩还原更准确
- 支持日间/夜间统一模型（全天候去雨）

**创新贡献**：
- 扩展应用场景：从白天去雨到全天候去雨
- 充分利用现有INR框架的灵活性
- 与隐式神经表示紧密结合（非简单前处理）
- 提供新视角：色彩空间也是可以学习的

## 三个创新点总体关系

| 创新点 | 关注维度 | 互补关系 |
|--------|---------|---------|
| RFM | 频域特征增强 | 基础模块，抑制雨纹频率成分 |
| MFGCP | 空间梯度+频域协同 | 与RFM互补，强化细节恢复 |
| SACS-IIG | 色彩空间+光照 | 扩展场景，全天候适应 |

**论文书写方向建议**：
- 创新点1（RFM）：频域特征增强
- 创新点2（MFGCP）：频率-空间协同感知
- 创新点3（SACS-IIG）：全天候自适应去雨
